# ISW Webpay Example

A demo Flutter app showing how to integrate the `isw_webpay` package for Interswitch payments.

## Running the Example

1. Navigate to this directory:
   ```bash
   cd example
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
